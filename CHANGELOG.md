# История изменений

## 2026-08-10 — задача 011

- Подготовлен production Compose для standalone Next.js, Directus 11 и PostgreSQL с внутренней сетью, persistent volumes, healthchecks, restart policy и ограничением Docker logs.
- Добавлены multi-stage Dockerfile, production env-шаблон и отдельный внутренний URL Directus для серверных CMS-запросов без утечки Docker hostname в публичные ссылки.
- Подготовлены Nginx reverse proxy для основного и административного доменов, ACME bootstrap и процедура Let’s Encrypt/Certbot без выполнения реального deployment.
- `DEPLOY.md` дополнен инструкциями по DNS, firewall, первому запуску, Directus schema/admin, backup/restore, обновлению, rollback и smoke-check; в P7 закрыта только production-конфигурация.

## 2026-08-08 — задача 010

- В footer добавлен ненавязчивый доступный переход в штатную Directus Studio, открывающийся в новой вкладке с безопасными атрибутами.
- URL админ-панели вынесен в `NEXT_PUBLIC_ADMIN_URL`; без корректного HTTP(S) URL ссылка полностью отсутствует в разметке.
- Зафиксированы границы безопасности Directus: штатная авторизация, минимальные роли и отсутствие административных прав у public policy.
- План проекта актуализирован: неподдерживаемый сценарий предзаполненного сообщения удалён из P3, переход в Directus добавлен в P4.

## 2026-08-08 — задача 009

- Финализированы metadata, canonical и Open Graph главной и блога через единый конфиг `SITE_URL`; существующий `public/og.png` сохранён глобальным fallback.
- Добавлены отказоустойчивый sitemap опубликованных статей, robots и фактическая JSON-LD-разметка `Organization`, `WebSite` и `BlogPosting`.
- Подготовлена неблокирующая SPA-интеграция Яндекс.Метрики из environment и централизованные события Telegram/MAX с параметром расположения CTA.
- Временные юридические страницы закрыты от индексации; production-домен, реальный ID счётчика и юридическая проверка аналитики оставлены явными блокерами запуска.

## 2026-08-08 — задача 008

- Видеоблок, финальный оффер, композиция с тханкой и Гималаями и footer объединены в единую завершающую сцену главной страницы.
- Технический заголовок о тханках заменён на клиентский CTA «Получите оценку вашего предмета»; Telegram и MAX сохранены как главные действия.
- Тханка и горный фон получили самостоятельную адаптивную композицию для desktop, tablet и mobile без новых изображений.
- Юридические ссылки и копирайт интегрированы в финальный экран; блокер по RuTube URL и финальным юридическим текстам сохранён.

## 2026-08-08 — задача 007

- Directus 11.17.4 выбран и настроен как CMS блога; схема `articles` и минимальные публичные права воспроизводятся из репозитория.
- `/blog` и `/blog/[slug]` переведены с mock-данных на серверный data-access слой с revalidation и контролируемым поведением при недоступной CMS.
- Добавлены rich content с серверной очисткой, оптимизированные изображения Directus, draft/published workflow и SEO/OG fallback-поля.
- Статический export отключён в пользу Next.js server runtime; добавлена единая инструкция по развёртыванию CMS и работе редактора.
