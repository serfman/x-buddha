# Промпт для Codex

Полностью изучи `client_tz.md`, `docs/architecture/frontend-prototype.md`, `docs/ui/design-direction.md`, `docs/tasks/001-codex-frontend-prototype.md` и содержимое `public/seed_photos/`.

Затем с нуля реализуй frontend-макет X-Buddha строго по задаче `docs/tasks/001-codex-frontend-prototype.md`.

Используй Next.js 15+, App Router, TypeScript и Tailwind CSS. Сейчас нужен только frontend: без backend, CMS, API, форм, загрузки файлов, Supabase и авторизации.

Не добавляй новые смысловые секции и не используй внешние изображения. Назначение локальных фото определяй по именам: `slider`, `center`, `footer`.

Сначала коротко опиши план работ и предполагаемую структуру файлов, затем реализуй проект. После реализации выполни `npm run lint` и `npm run build`, исправь ошибки и дай краткий отчёт.
