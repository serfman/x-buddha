## Расчёт прогресса

Для каждого этапа прогресс рассчитывается по формуле:

`progress = completed_work_items / total_work_items * 100`

Правила расчёта:

1. Учитываются только work items текущей версии этого документа; каждый пункт имеет одинаковый вес.
2. `[x]` означает завершённый пункт, `[ ]` — незавершённый; частично выполненный пункт остаётся незавершённым.
3. Процент округляется до ближайшего целого числа. При изменении состава обязательных work items знаменатель меняется.
4. Этап получает 100% только после завершения всех его work items.
5. Progress bar состоит из 10 символов: число заполненных сегментов равно `floor(progress / 10)`, остальные сегменты отображаются символом `░`; для 100% используются 10 заполненных сегментов.
