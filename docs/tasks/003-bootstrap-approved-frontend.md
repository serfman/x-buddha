# Задача 003. Bootstrap утверждённого frontend-проекта

## Цель

Создать рабочую frontend-основу проекта X-Buddha в репозитории и перенести в неё утверждённую клиентом визуальную концепцию.

После выполнения задачи проект должен стать полноценной отправной точкой дальнейшей разработки.

В рамках этой задачи backend, CMS, база данных и внешние интеграции не создаются.

---

Репозиторий:

`serfman/x-buddha`

Утверждённый концепт:

[https://x-buddha-expert.woolly-pear-3006.chatgpt.site/](https://x-buddha-expert.woolly-pear-3006.chatgpt.site/)

Основные требования находятся в:

- client_[tz.md](http://tz.md)

- docs/[project-plan.md](http://project-plan.md)

- docs/architecture/[frontend.md](http://frontend.md)

Изображения располагаются в:

`public/seed_photos/`

Назначение изображений определяется по имени файла:

- `slider` — Hero;

- `center` — блок факторов оценки;

- `footer` — финальный экран.

# Технологии

Использовать:

- Next.js (App Router);

- TypeScript;

- Tailwind CSS;

- React Server Components по умолчанию;

- Client Components только при необходимости.

Не использовать:

- backend;

- CMS;

- Supabase;

- базу данных;

- формы;

- загрузку файлов.

## 3. Перенос утверждённого концепта

Перенести в проект:

- Header;

- Hero;

- автоматический слайдер;

- блок факторов оценки;

- блок инструкции;

- отдельный блок видео;

- финальный экран;

- страницы `/blog`;

- `/blog/[slug]`;

- кнопки Telegram, WhatsApp и MAX;

- mobile-кнопку «Написать».

Не добавлять новые смысловые блоки.

---

## 4. Правки клиента

### Hero

В заголовке

> Оценка и атрибуция буддийских статуэток и артефактов

слова

**«буддийских статуэток»**

должны стать главным типографическим акцентом.

При этом:

- H1 остаётся единым;

- SEO не ухудшается;

- переносы работают корректно;

- mobile не ломается.

---

### Типографическая система

Устранить ощущение однообразия текста.

Использовать полноценную систему типографики:

- Display;

- H1;

- H2;

- H3;

- Body;

- Small;

- Eyebrow.

Использовать различия:

- размера;

- насыщенности;

- интерлиньяжа;

- трекинга;

- цвета.

Не добавлять новый текст только ради оформления.

## 6. Производительность

Использовать:

- next/image;

- lazy loading;

- корректный aspect ratio;

- object-fit;

- prefers-reduced-motion.

Не использовать:

- тяжёлый canvas;

- постоянные GPU-анимации;

- неоптимизированные изображения.

## 7. Адаптивность

- 768 px;

- корректная типографика;

- корректный акцент H1;
