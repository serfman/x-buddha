# Задача 006. Синхронизация контента и мессенджеров с client_[tz.md](http://tz.md)

## Цель

Привести текущий сайт X-Buddha в точное соответствие актуальному `client_tz.md` по текстам и каналам связи.

В рамках задачи:

- проверить все тексты сайта;

- заменить несоответствующие формулировки на тексты из `client_tz.md`;

- подключить реальные Telegram и MAX;

- полностью удалить WhatsApp;

- сохранить текущие изображения без изменений;

- оставить RuTube как заглушку до получения реальной ссылки.

Не менять утверждённый дизайн, структуру сайта и архитектуру без необходимости.

---

# 1. Источник истины

Для текстов и контактов использовать:

`client_tz.md`

Он является источником истины для:

- текстов основных блоков;

- состава услуг;

- формулировок CTA;

- Telegram;

- MAX;

- состава мессенджеров.

Не переписывать клиентские тексты «красивее» или «маркетинговее».

Если текущий сайт расходится с `client_tz.md`, привести сайт к `client_tz.md`.

---

# 2. Проверка текстов главной страницы

Проверить все основные секции.

Минимум:

## Hero

Сверить:

- X-Buddha — экспертный центр;

- Будды, атрибутика и артефакты буддизма;

- Оценка;

- выкуп;

- атрибуция;

- экспертиза;

- размещение на аукционе.

Проверить блок «Что входит в услугу»:

- Атрибуция: определение возраста, школы, мастера и культурной ценности.

- Честная оценка: расчёт реальной рыночной и коллекционной стоимости.

- Быстрый выкуп: выплата денег сразу удобным для вас способом.

Сохранить согласованный визуальный акцент H1, если он не противоречит фактическому тексту.

---

## Факторы оценки

Проверить соответствие названий и описаний:

- Время изготовления;

- Место производства;

- Техника и стиль;

- Школа и мастер;

- Размер и вес предмета;

- Состояние.

Тексты должны соответствовать `client_tz.md`.

Не менять уже реализованную привязку маркеров и линий.

---

## «Как узнать стоимость прямо сейчас?»

Сверить текст с `client_tz.md`.

Обязательные смысловые элементы:

- оценка полностью онлайн;

- фотографии с разных ракурсов;

- обязательно основание / дно;

- лицо;

- детали крупным планом;

- отправка через мессенджер;

- размеры;

- вес;

- история происхождения;

- сообщение о конфиденциальности.

Не добавлять форму загрузки файлов.

Проверить:

- тханки / картины Тибета;

- Гималаи;

- X-Buddha © 2026.

# 3. Мессенджеры

Актуальная схема связи:

- Telegram;

- MAX.

WhatsApp должен быть полностью удалён с сайта.

Удалить WhatsApp из:

- Header CTA, если присутствует;

- Hero;

- блока «Как узнать стоимость»;

- финального экрана;

- mobile bottom sheet;

- Floating Contact;

- blog CTA;

- конфигурации;

- компонентов;

- mock-данных;

- accessibility labels;

- любых скрытых или резервных ссылок.

Не оставлять неиспользуемую WhatsApp-конфигурацию.

---

# 4. Telegram и MAX

Использовать реальные ссылки из актуального `client_tz.md`.

Не хардкодить ссылки в нескольких компонентах.

Хранить централизованно, например:

`src/data/messengers.ts`

или в существующем эквивалентном конфигурационном файле.

Все CTA Telegram должны ссылаться на один источник.

Все CTA MAX должны ссылаться на один источник.

Проверить desktop и mobile.

---

# 5. Поведение кнопки «Написать»

На mobile:

по нажатию открывается bottom sheet только с:

- Telegram;

- MAX.

WhatsApp не показывать.

На desktop:

использовать текущую логику проекта, но только с Telegram и MAX.

Не менять UX без необходимости.

---

# 6. Изображения

Текущие изображения считаются утверждёнными.

Не:

- заменять;

- генерировать;

- переименовывать без необходимости;

- менять композицию;

- проводить дополнительную визуальную переработку.

P2 work item «Получить и установить финальные изображения» считать выполненным, если проект уже использует согласованный текущий набор изображений.

---

# 7. Alt-тексты

Проверить существующие alt-тексты.

Для текущих финальных изображений:

- добавить корректные alt там, где изображение несёт смысл;

- для декоративных изображений использовать пустой alt;

- не использовать SEO-спам.

Если alt уже корректны — не менять.

---

# 8. RuTube

Реальной ссылки пока нет.

Сохранить текущую заглушку.

Проверить:

- URL вынесен в централизованную конфигурацию;

- отсутствие реального URL не ломает интерфейс;

- компонент готов к последующей замене одной настройкой.

Не придумывать ссылку.

P2 work item по RuTube оставить незавершённым.

- без WhatsApp.
