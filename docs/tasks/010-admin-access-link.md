# Задача 010. Ссылка на админ-панель Directus

## Цель

Добавить на публичный сайт X-Buddha аккуратный и ненавязчивый переход в админ-панель Directus.

Адрес админки:

`https://admin.x-buddha.ru`

Не создавать собственную страницу авторизации и не реализовывать отдельную систему аутентификации.

Использовать штатную авторизацию Directus.

---

## 1. Ссылка в Footer

Добавить в footer маленькую иконку-шестерёнку.

Требования:

- визуально второстепенная;

- не конкурирует с Telegram, MAX и юридическими ссылками;

- соответствует текущей стилистике сайта;

- размер достаточный для доступного клика;

- имеет hover/focus state;

- `aria-label="Админ-панель"`.

По клику:

- открыть `https://admin.x-buddha.ru`;

- в новой вкладке;

- использовать безопасные атрибуты для внешней ссылки.

Не добавлять текст «Админка» рядом с иконкой.

---

## 2. Конфигурация

Не хардкодить URL непосредственно в Footer.

Добавить централизованную настройку, например:

`NEXT_PUBLIC_ADMIN_URL`

Значение production:

`https://admin.x-buddha.ru`

Добавить переменную в `.env.example`.

Если URL не задан:

- не показывать иконку;

- не оставлять нерабочую ссылку.

---

## 3. Directus

Проверить текущую конфигурацию Directus.

Админ-панель должна использовать существующий Directus instance и штатный login Directus.

Не создавать:

- собственный `/admin`;

- собственную страницу login;

- прокси-авторизацию через Next.js;

- дополнительную базу пользователей.

---

## 4. Безопасность

Наличие ссылки на админ-панель не считается механизмом защиты.

Безопасность должна обеспечиваться самим Directus:

- только авторизованные пользователи;

- сильные пароли;

- минимально необходимые роли;

- отсутствие публичных административных permissions.

Не пытаться скрывать Directus как средство безопасности.

Не индексировать admin URL в sitemap сайта.

---
