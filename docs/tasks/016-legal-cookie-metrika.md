# 1. Политика конфиденциальности

Подготовить рабочую страницу:

`/privacy`

За основу по структуре и подходу взять LikeGallery, адаптировав документ под фактическую работу X-Buddha.

Учитывать:

- на сайте нет форм обратной связи;

- пользователь не загружает фотографии непосредственно на сайт;

- фотографии отправляются через внешние мессенджеры;

- используются Telegram и MAX;

- используется Яндекс.Метрика;

- могут существовать необходимые технические cookies/идентификаторы и server logs;

- блог работает через Directus;

- Directus admin не является пользовательским интерфейсом сайта.

Не заявлять о сборе данных, которого фактически нет.

Не придумывать:

- ФИО владельца;

- ИП/ООО;

- ИНН;

- ОГРН;

- адрес;

- телефон;

- email.

Контакт по вопросам сайта:

`Telegram: @Lanumax`

Сделать Telegram кликабельным через существующую/корректную ссылку.

# 2. Публичная оферта

Подготовить:

`/offer`

За основу по структуре и логике использовать документ LikeGallery, но адаптировать его к фактической модели X-Buddha.

Не копировать условия, которые не соответствуют работе X-Buddha.

Учитывать:

- сайт является информационной площадкой экспертного центра;

- через сайт не осуществляется онлайн-оплата;

- нет корзины;

- нет checkout;

- нет автоматического заключения сделки через интерфейс сайта;

- первичное обращение происходит через Telegram/MAX;

- конкретные условия оценки, выкупа или иных услуг могут согласовываться отдельно.

Не придумывать юридические реквизиты владельца.

Контакт:

`Telegram: @Lanumax`

Если термин «публичная оферта» юридически противоречит фактическому содержанию документа без идентификации стороны либо документ LikeGallery невозможно корректно адаптировать без данных владельца — не маскировать проблему текстом.

В таком случае зафиксировать blocker и предложить более корректное название/формат документа, не меняя решение самостоятельно.

# 5. Cookie Consent

Добавить компактный cookie-banner в стилистике X-Buddha.

Он не должен выглядеть как стандартный яркий рекламный popup.

Пример смысла текста:

«Мы используем файлы cookie и Яндекс.Метрику для анализа работы сайта.»

Добавить ссылку:

`Политика конфиденциальности`

---

# 6. Consent UX

Пользователю должны быть доступны как минимум:

- «Принять»;

- «Отклонить».

Не использовать dark patterns.

«Отклонить» не прятать и не делать намеренно труднодоступным.

После выбора сохранить решение пользователя локально.

Баннер не должен появляться повторно при каждом переходе между страницами.

Предусмотреть версионирование consent, чтобы при существенном изменении политики решение пользователя можно было запросить повторно.

# 7. Яндекс.Метрика

Счётчик уже был подключён ранее.

Не создавать новую интеграцию и не требовать новый ID.

Найти существующую реализацию и проверить production-конфигурацию.

Проверить:

- реальный ID счётчика;

- загрузку Метрики;

- существующие события;

- `messenger_telegram_click`;

- `messenger_max_click`;

- отсутствие дублирующей инициализации.

---

# 8. Consent и Метрика

До согласия пользователя аналитический счётчик, если технически возможно в рамках текущей интеграции, не должен запускать необязательное аналитическое отслеживание.

При:

`Принять`

→ разрешить/инициализировать аналитику.

При:

`Отклонить`

→ не запускать необязательную аналитику.

При уже сохранённом согласии:

→ не показывать баннер повторно и корректно применять выбор.

Проверить поведение после reload и navigation.

Не ломать SSR/hydration.

---

# 9. Функциональность без consent

Отказ от аналитических cookies не должен влиять на:

- просмотр сайта;

- блог;

- Telegram;

- MAX;

- навигацию;

- изображения;

- Directus content.

Основной функционал сайта должен оставаться доступным.
