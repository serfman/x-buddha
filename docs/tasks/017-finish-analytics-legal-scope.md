## 2. Cookie consent

Сохранить реализованную в задаче 016 модель:

- до согласия пользователя Метрика не загружается;

- «Принять» разрешает загрузку аналитики;

- «Отклонить» не загружает необязательную аналитику;

- отказ не ограничивает функциональность сайта;

- решение пользователя сохраняется;

- баннер не появляется повторно без необходимости.

Проверить это уже с реальным production ID.

## 3. Проверка Метрики

На production проверить:

- загрузку счётчика после consent;

- отсутствие загрузки до consent;

- отсутствие загрузки после отказа;

- отсутствие повторной/двойной инициализации;

- корректность SPA-навигации, если она обрабатывается существующей интеграцией.

Проверить отсутствие runtime errors.

## 5. Публичная оферта

Принято продуктовое решение:

**публичную оферту на X-Buddha не размещать.**

Причины:

- сайт не содержит checkout;

- нет корзины;

- нет онлайн-оплаты;

- через сайт не заключается автоматическая сделка;

- конкретные условия оценки, выкупа и иных взаимодействий согласовываются непосредственно с клиентом через мессенджеры;

- клиент не предоставляет публичные реквизиты стороны для оферты.

Не создавать обезличенную фиктивную оферту.
