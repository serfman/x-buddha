# 1. Убрать «Оценить предмет» из Hero на mobile

## Проблема

Кнопка «Оценить предмет» на мобильном первом экране не даёт отдельной ценности:

- она только прокручивает пользователя к другому CTA-блоку;

- рядом уже доступны прямые кнопки Telegram и MAX;

- пользователь может сразу перейти в нужный мессенджер без промежуточного шага.

## Требование

На mobile полностью убрать кнопку:

`Оценить предмет`

из Hero.

Оставить только:

- Telegram;

- MAX.

Messenger-кнопки сохранить в текущем полноценном виде с названиями.

Существующие URL и analytics events не менять.

Desktop не менять, если там кнопка всё ещё является частью утверждённого дизайна.

# 2. Переделать sticky-блок факторов оценки

## Проблема текущей реализации

После задачи 021 пункты факторов прокручиваются поверх изображения статуэтки.

Это ухудшает:

- читаемость;

- восприятие статуэтки;

- связь между изображением и текстом;

- компактность блока.

Кроме того, между пунктами появился слишком большой вертикальный интервал.

---

# 3. Требуемое поведение

На mobile:

1. изображение статуэтки располагается сверху блока;

2. изображение остаётся sticky в верхней части экрана;

3. текстовые пункты 01–06 идут обычным плотным вертикальным списком ПОД изображением;

4. пункты не накладываются на изображение;

5. карточки не перекрывают статуэтку;

6. между пунктами сохраняются умеренные стандартные интервалы, как было до задачи 021;

7. после окончания списка sticky-состояние изображения корректно завершается.
